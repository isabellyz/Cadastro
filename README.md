# Sistema de Cadastro de Funcionários

Este projeto é um **sistema de cadastro de funcionários** desenvolvido em **PHP e HTML**, com o objetivo de demonstrar operações básicas de **CRUD** (Create, Read, Update, Delete) em um ambiente web simples e funcional.

## Descrição

O sistema permite o **cadastro, visualização, edição e exclusão** de funcionários em um banco de dados.  
Cada funcionário possui informações como:

- Nome completo  
- Cargo  
- Departamento  
- E-mail  
- Telefone  
- Data de admissão  

A interface foi construída com HTML e estilizada de forma simples para facilitar o uso e a compreensão do funcionamento do sistema.

## ⚙️ Funcionalidades

✅ Cadastrar novos funcionários  
✅ Listar funcionários cadastrados  
✅ Editar informações existentes  
✅ Excluir registros
